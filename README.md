An entry for the [make.fun bounty "Two Lines of Morning Light"](https://make.fun/bounty/u-gudril-cool-two-lines-of-morning-light-ade94fc5): a single original two-line micro poem about light and morning, at most 120 characters including the line break. The program writes the poem to `entry.txt` — nothing else.

> Morning light slips under the door, a thin blade,
> and the floor gives it somewhere to stand.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

This writes `out/entry.txt` containing the two-line poem (92 characters including the line break). Requires Node 22. No dependencies, no network — the output is fully deterministic.
